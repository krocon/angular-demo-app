# API notes – video scripts vs. installed Angular

Verified against the typings in `node_modules/@angular/*` of **Angular 22.2.1**, **Material/CDK 22.2.1**
and **@angular/cli 22.2.1** (October 2026). The video scripts were not part of this workspace, so the
summaries in the generation prompt were used as the source of truth for the content.

Stability legend (from the JSDoc tags in the `.d.ts` files): `@publicApi` = stable,
`@developerPreview`, `@experimental`.

## Other notes

- **Fonts** are self-hosted (`@fontsource/roboto`, `material-symbols`). The default `ng add` setup
  links Google Fonts, and the production build then tries to inline them, which fails without
  network access.
- **GUI Expert Table** (`@guiexpert/angular-table@22.1.84`, MIT) declares `peerDependencies`
  `@angular/core ^22.0.1` and works zoneless. Gotcha: pass `columnSizes`, otherwise all columns are
  0 px wide. It ships its CSS inside the component (`ViewEncapsulation.None`); its CSS variables
  are mapped to Material tokens so it follows dark mode.
- **Initial budget:** raised from 500 kB to 650 kB (warning) – see README → Budgets.
- **Grep-based checks** (DoD): legacy patterns such as `*ngIf`, `@Input()`, `constructor(private`,
  `BehaviorSubject` intentionally appear inside _strings_ in `*.snippets.ts`, `ai-examples.ts` and
  the analyzer rules (they are the "before" code and test data). ESLint checks the real code via the
  AST (`no-restricted-syntax` for legacy decorators, `prefer-inject`, `prefer-control-flow`, …).
