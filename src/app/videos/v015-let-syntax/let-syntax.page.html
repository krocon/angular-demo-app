Rules

  • Read-only: you can't assign to a @let in an event handler.
  • Block-scoped: the same name in two blocks is two variables:
@if (true) { @let label = 'from block A'; {{ label }} } @if (true) { @let label = 'from block B'; {{ label }} }

For conditional rendering keep using @if – @let only names values.
